# 1.0.0

- First public release of Block Remap.
- Configure individual block replacements for world generation or global standard writes.
- Edit rules with F9 or `/blockgenban`; search source and target blocks independently and browse creative categories.
- Configured source blocks appear first and retain that position after saving and reopening the screen.
- Disable structures and features by registry ID.
- Minecraft 1.20.1 Forge and Fabric, Minecraft 1.21.1 NeoForge.
- MIT license for code; separate project artwork terms.
