# Contributing / 贡献

Open an issue before proposing a larger behavior change. For a fix, describe its trigger and affected Minecraft/loader version, keep the patch focused, and include the relevant build or game-test result. Update matching descriptions and translations when behavior changes.

Use the existing class responsibilities and short names. Chinese-first bilingual comments should explain constraints or intent. Keep client-only initialization out of dedicated-server code. Do not include game worlds, caches, credentials or copied third-party assets.

提交较大功能前先说明用途。修复请附触发条件、MC/加载器版本与相关验证。行为改变时同步说明和翻译。沿用短职责名，用中英注释解释限制，隔离客户端初始化，不提交存档、缓存、凭据或第三方资源。

Code contributions are accepted under MIT. Artwork contributions must identify their source and proposed license separately.

代码贡献按 MIT 接收，美术贡献另列来源与授权范围。
